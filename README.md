# Gather — Event Management Website

A responsive event discovery and registration website built for the K Explore Web Designing assignment.

## Features
- Responsive homepage with hero section, featured events, and about section
- Event cards with date, venue, category, and description
- Search events by keyword
- Filter events by category
- Event registration modal with HTML and JavaScript validation
- Confirmation toast after successful registration
- Registration data stored in browser Local Storage
- Dark/light mode toggle with saved preference
- Responsive mobile navigation
- Newsletter email form validation

## Tech stack
- HTML5
- CSS3
- Vanilla JavaScript
- Git and GitHub for version control

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.
3. No build tools or dependencies are required.

## Registration data
Successful registrations are stored in Local Storage under `gatherRegistrations`. This is a front-end demonstration and does not send information to a server.

## Deployment
Deploy the repository using GitHub Pages, Netlify, or Vercel. For GitHub Pages, open **Settings → Pages**, select the main branch and root folder, and save.
